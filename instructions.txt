# Instruções do Projeto Pizza Express Frontend

## Linting
- Para rodar o lint, utilize o comando `npm run lint`. Este comando utiliza o script configurado no `package.json` que é otimizado para projetos Next.js.
- O comando `npx eslint .` pode gerar erros porque executa o ESLint diretamente, sem utilizar as configurações específicas do Next.js definidas no `.eslintrc.json`.

## Scripts disponíveis
- `npm run dev`: Inicia o servidor de desenvolvimento utilizando o Turbopack.
- `npm run build`: Realiza o build do projeto.
- `npm run start`: Inicia o servidor de produção.
- `npm run lint`: Executa o linting do código.
- `npm run test`: Executa os testes utilizando o Jest.

## Dependências
- React e React DOM versão 19.
- Next.js versão 15.3.4.
- TypeScript versão 5 e suas definições de tipo.
- ESLint versão 9 e configuração para Next.js.
- Jest versão 29 para execução dos testes.
- @testing-library/react versão 13 para testes de componentes React.
- @testing-library/jest-dom versão 5 para matchers adicionais em testes.
- jest-environment-jsdom versão 29 para simulação do DOM em testes.

## Testes
- O ambiente de testes foi configurado utilizando Jest.
- Para rodar os testes, utilize o comando `npm run test`. Este comando executa o Jest com as configurações definidas.
- Um teste de exemplo foi criado em `__tests__/sample.test.js` para validar o ambiente.
- O ambiente está funcional e todos os testes passam.

## Configurações adicionais
- Babel configurado com os presets `@babel/preset-env` e `@babel/preset-react`.
- ESLint configurado para Next.js.
- Testes utilizam o ambiente `jest-environment-jsdom` para simular o DOM.

## Configuração de Testes

### Caminho Percorrido
1. Inicialmente, configuramos o Jest com suporte a Babel para transformar arquivos JSX e TypeScript.
2. Removemos o Babel para garantir compatibilidade com o Turbopack, ajustando o Jest para usar CommonJS.
3. Enfrentamos erros de sintaxe relacionados ao uso de `import` no Jest.
4. Pesquisamos na documentação oficial do Jest e confirmamos que o suporte a ESM é experimental e instável.
5. Ajustamos o Jest para usar `ts-jest` como transformador, garantindo suporte a TypeScript e JSX.
6. Configuramos o ESLint para permitir o uso de `require()` nos arquivos de teste.
7. Validamos os testes com sucesso após ajustar o Jest para usar CommonJS e corrigir as configurações do ESLint.

### Comando para Testes
- Utilize `npm run test` para executar os testes com Jest configurado para CommonJS e `ts-jest`.
