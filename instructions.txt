# Instruções do Projeto Pizza Express Frontend

## Estrutura de Pastas
- `app/`: Contém os arquivos principais do App Router do Next.js, incluindo `layout.tsx` e `page.tsx`.
- `components/`: Contém componentes reutilizáveis, como `TestChakra` e `ui/provider.tsx`.
- `public/`: Contém arquivos estáticos, como imagens e ícones.
- `__tests__/`: Contém os arquivos de teste, como `sample.test.js`.

## Configuração do Ambiente

### Dependências
- React e React DOM versão 19.
- Next.js versão 15.3.4.
- TypeScript versão 5 e suas definições de tipo.
- ESLint versão 9 configurado para Next.js.
- Jest versão 29 para execução dos testes.
- @testing-library/react versão 13 para testes de componentes React.
- @testing-library/jest-dom versão 5 para matchers adicionais em testes.
- jest-environment-jsdom versão 29 para simulação do DOM em testes.
- Chakra UI e dependências relacionadas:
  - `@chakra-ui/react`
  - `@emotion/react`
  - `@emotion/styled`
  - `framer-motion`
  - `next-themes`

### Scripts Disponíveis
- `npm run dev`: Inicia o servidor de desenvolvimento utilizando o Turbopack.
- `npm run build`: Realiza o build do projeto.
- `npm run start`: Inicia o servidor de produção.
- `npm run lint`: Executa o linting do código.
- `npm run test`: Executa os testes utilizando o Jest.

## Teste do Chakra UI
- Foi criado o componente `TestChakra` em `components/TestChakra.tsx` para verificar o funcionamento do Chakra UI.
- O componente foi adicionado à página inicial (`app/page.tsx`) para facilitar o teste visual.
- Para testar, inicie o servidor de desenvolvimento com `npm run dev` e acesse a página inicial.

## Configuração de Testes
- O ambiente de testes foi configurado utilizando Jest com suporte a TypeScript e JSX.
- Utilize `npm run test` para executar os testes.
- Um teste de exemplo foi criado em `__tests__/sample.test.js`.

## Linting
- Para rodar o lint, utilize o comando `npm run lint`. Este comando utiliza o script configurado no `package.json` que é otimizado para projetos Next.js.
- O comando `npx eslint .` pode gerar erros porque executa o ESLint diretamente, sem utilizar as configurações específicas do Next.js definidas no `.eslintrc.json`.
