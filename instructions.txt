# Instruções do Projeto Pizza Express Frontend

## Estrutura de Pastas
- `app/`: Contém os arquivos principais do App Router do Next.js, incluindo `layout.tsx` e `page.tsx`.
- `components/`: Contém componentes reutilizáveis, como `TestChakra` e componentes UI.
- `public/`: Contém arquivos estáticos, como imagens e ícones.
- `__tests__/`: Contém os arquivos de teste, como `home.test.js` e `sample.test.js`.
- `theme/`: Contém a configuração do tema do Chakra UI (`theme.ts`).

## Configuração do Ambiente

### Dependências
- React e React DOM versão 19.
- Next.js versão 15.3.4.
- TypeScript versão 5 e suas definições de tipo.
- ESLint versão 9 configurado para Next.js.
- Jest versão 29 para execução dos testes.
- @testing-library/react versão 13 para testes de componentes React.
- @testing-library/jest-dom versão 5 para matchers adicionais em testes.
- jest-environment-jsdom versão 29 para simulação do DOM em testes.
- Chakra UI e dependências relacionadas:
  - `@chakra-ui/react`
  - `@emotion/react`
  - `@emotion/styled`
  - `framer-motion`
  - `next-themes`

### Scripts Disponíveis
- `npm run dev`: Inicia o servidor de desenvolvimento com o compilador SWC.
- `npm run build`: Realiza o build do projeto.
- `npm run start`: Inicia o servidor de produção.
- `npm run lint`: Executa o linting do código.
- `npm run test`: Executa os testes utilizando o Jest.

## Sistema de Temas (Chakra UI)
- O projeto utiliza Chakra UI v3 para componentes de interface e estilização.
- A configuração do tema personalizado está em `theme/theme.ts`.
- O tema define cores personalizadas para o aplicativo de pizzaria:
  - `brand.red`: Tomate, Pepperoni (#D92B2B)
  - `brand.green`: Manjericão, Pesto (#228B22)
  - `brand.yellow`: Queijo (#FFC72C)
  - `brand.beige`: Massa, Crosta (#F5DEB3)
  - `brand.brown`: Forno a lenha, Crosta mais escura (#A0522D)
  - `brand.charcoal`: Lousa, Acentos escuros (#36454F)
  - `brand.cream`: Mozzarella, Fundo claro (#FFFDD0)
- O tema é aplicado através do `ChakraProvider` em `app/provider.tsx`.
- O aplicativo também suporta tema escuro/claro usando `next-themes`.
- Foi criado o componente `TestChakra` em `components/TestChakra.tsx` para verificar o funcionamento do Chakra UI.
- O componente foi adicionado à página inicial (`app/page.tsx`) para facilitar o teste visual.

## Configuração de Testes
- O ambiente de testes foi configurado utilizando Jest com suporte a TypeScript e JSX.
- Os testes são executados com SWC (não Babel) para maior performance.
- Utilize `npm run test` para executar os testes.
- Testes de exemplo:
  - `__tests__/sample.test.js` - Teste básico para verificar a configuração.
  - `__tests__/home.test.js` - Teste da página inicial com mock dos componentes Chakra.

## Configuração do Compilador SWC
- O projeto utiliza o compilador SWC do Next.js para maior performance.
- A configuração do SWC está no arquivo `next.config.mjs`:
  ```javascript
  const nextConfig = {
    experimental: {
      optimizePackageImports: ["@chakra-ui/react"],
    },
    swcMinify: true,
  };
  ```
- O SWC é significativamente mais rápido que o Babel para compilação e Hot Module Replacement.
- Os testes também usam SWC através do transformer configurado no `jest.config.js`.

## Linting
- Para rodar o lint, utilize o comando `npm run lint`. Este comando utiliza o script configurado no `package.json` que é otimizado para projetos Next.js.
- O comando `npx eslint .` pode gerar erros porque executa o ESLint diretamente, sem utilizar as configurações específicas do Next.js definidas no `.eslintrc.json`.
