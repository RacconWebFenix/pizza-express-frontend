Resumo do Projeto Fullstack: pizza-express
Data: 19 de junho de 2025 (atualizado)

---
FRONTEND
---
Stack principal:
- Next.js 15 (App Router)
- TypeScript
- Chakra UI (ColorMode, Toaster customizados)
- next-themes para tema dark/light
- React 19

Estrutura de pastas:
- app/: páginas, layout, estilos globais
- components/ui/: Provider, ColorMode, Toaster, Tooltip
- public/: SVGs
- Configurações: package.json, tsconfig.json, next.config.mjs/ts

Funcionalidades prontas:
- Tema claro/escuro
- Notificações (toaster)
- Tooltips customizados
- Pronto para deploy em Vercel

---
BACKEND
---
API REST para pizzaria (NestJS, Prisma, PostgreSQL)

Tecnologias:
- Node.js + NestJS
- Prisma ORM + PostgreSQL
- class-validator
- JWT (autenticação)
- Jest + Supertest (e2e)
- GitHub Actions (CI/CD)

Estrutura:
- src/: auth, clientes, entregadores, pizzas, pedidos
- prisma/: migrations, schema, seed
- test/: testes e2e

Funcionalidades:
- CRUD completo (clientes, entregadores, pizzas, pedidos)
- Autenticação JWT
- Documentação Swagger em /api
- Testes e2e automatizados

---
Integração Frontend + Backend:
- Frontend consome endpoints REST do backend
- Autenticação JWT para rotas protegidas
- Fluxo de pedidos, cadastro, etc, via HTTP

Use este resumo como contexto para futuras criações, integrações ou modificações neste projeto fullstack.
