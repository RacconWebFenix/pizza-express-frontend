Documentação das rotas e payloads do CRUD de cadastro de cliente para o frontend e aplicação com IA


1. Criar Cliente
Método: POST
Endpoint: /clientes
Payload:
{
  "nome": "string",
  "email": "string",
  "telefone": "string",
  "endereco": "string"
}
Resposta:
{
  "id": "number",
  "nome": "string",
  "email": "string",
  "telefone": "string",
  "endereco": "string",
  "createdAt": "datetime"
}
Observação: O endereço NÃO deve ser enviado na rota de cadastro de cliente. O endereço será solicitado apenas na rota de cadastro ou edição de endereço para aquele cliente.

2. Listar Clientes
Método: GET
Endpoint: /clientes
Resposta:
[
  {
    "id": "number",
    "nome": "string",
    "email": "string",
    "telefone": "string",
    "endereco": "string"
  }
]

3. Buscar Cliente por ID
Método: GET
Endpoint: /clientes/{id}
Resposta:
{
  "id": "number",
  "nome": "string",
  "email": "string",
  "telefone": "string",
  "endereco": "string"
}

4. Atualizar Cliente
Método: PUT
Endpoint: /clientes/{id}
Payload:
{
  "nome": "string",
  "email": "string",
  "telefone": "string",
  "endereco": "string"
}
Resposta:
{
  "id": "number",
  "nome": "string",
  "email": "string",
  "telefone": "string",
  "endereco": "string",
  "updatedAt": "datetime"
}

5. Deletar Cliente
Método: DELETE
Endpoint: /clientes/{id}
Resposta:
{
  "message": "Cliente removido com sucesso"
}
